VLM（とVLA）（その2／全2）

OSS: SmolVLA。

SmolVLA は、小型の VLA です。2025年6月の論文です。

論文によれば、10倍大きい VLA と同じくらいの性能で、1枚の GPU で学習でき、一般向けの GPU や CPU でも動かせます。コミュニティが安価なロボットで集めたデータで学習していて、コード、学習済みのモデル、学習データを公開しています。ロボット学習のライブラリ LeRobot の一部として提供されています。

ライセンスは、LeRobot のリポジトリの表記によれば Apache-2.0 です。モデルの重みのライセンスは確かめていません。

状態は研究段階です。LeRobot は、確認した時点で 0.6.1 で、1.0 の版が出ていないためです。

一次情報は、論文と、LeRobot の公式のリポジトリです。

論文: PaLM-E。

PaLM-E は、言語モデルを、身体を持つ作業に広げた、初期の VLM の論文です。2023年3月のものです。

言語モデルに、画像やロボットの状態をそのまま入力として与えて、一緒に学習させました。そして、ロボットの作業の計画、画像についての質問への回答、画像の説明を、1つのモデルでこなしました。論文によれば、Web の多様なデータで学習するほど、ロボットの作業の成績も上がりました。

ライセンスは、arXiv の標準の配布許諾です。状態は研究段階です。

論文: RT-2。

RT-2 は、VLM をそのままロボットの制御に使う VLA の、初期の代表的な論文です。2023年7月のものです。

ロボットの動作を、文字列、つまりトークンとして表しました。そして、Web の画像と文章のデータと、ロボットの動作のデータで、VLM を一緒に追加学習させました。その結果、学習のデータに無い物や指示にも対応できることを示しました。

ライセンスは、arXiv の標準の配布許諾です。状態は研究段階です。

製品: Gemini Robotics ER 2。

Gemini Robotics ER 2 は、Google DeepMind の、ロボットの「計画を立てる頭脳」に当たる VLM です。2026年7月に発表された、ER 1.6 の後継です。

人との会話、周囲の理解、何段階もの作業の計画、動画からの進み具合の把握、そして複数のロボットの連携を受け持ちます。実際の動作は、開発者が「道具」として登録した VLA などに任せます。

API として提供されています。状態は実用です。開発元によれば、Gemini API と Google AI Studio で、開発者が一般に使えるためです。

一次情報は、開発元の発表です。

製品: Gemini Robotics 2。

Gemini Robotics 2 は、Google DeepMind の VLA です。2026年7月に発表されました。

開発元によれば、人型ロボットの全身や、双腕のロボットを動かせて、手の細かな操作も扱います。ロボットの機器の上で動かす軽量版の On-Device 2 も、同時に発表されました。一方で、開発元自身も、多指の手の細かな操作はまだ難しく、作業によって成功率に大きな差があると述べています。

一般には提供されていません。状態は研究段階です。開発元によれば、早期アクセスのパートナーに限って提供しているためです。

一次情報は、開発元の発表です。

まとめ。

VLM はロボットの認識と計画を、VLA はそこから動作の出力までを受け持ちます。2023年の PaLM-E と RT-2 が、その初期の代表的な例です。

今では、NVIDIA の Cosmos 3 と Isaac GR00T が、オープンソースのまま実用の段階に入っています。一方、openpi、OpenVLA、SmolVLA は、研究段階のオープンソースです。

製品では、Gemini Robotics が、計画を立てる VLM の ER 2 と、動作を受け持つ VLA の Gemini Robotics 2 を組み合わせる形をとっています。ただし VLA の方は、まだ限られたパートナー向けの段階です。

以上で、VLM と VLA の話を終わります。
