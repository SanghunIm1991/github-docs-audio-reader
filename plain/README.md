# plain/ について

このフォルダの `.txt` は、`transcripts/` の原稿から Markdown の記号と URL を外した、コピペ用の素のテキストです。

2026-10-20 から、更新を止めています。音声づくりに使っている Gemini Notebook は、`transcripts/` の原稿を GitHub の URL から直接読めるためです。

ここにあるのは、2026-10-20 に作ったフェーズ3-1（`transcripts/ros2MinimalPhysicalAi/docs/phase3_1_pubsub.md`）の最初の版までを反映したものです。それより後に作った原稿や、後で直した原稿（フェーズ3-1 も含む）は反映していません。最新の内容は `transcripts/` を見てください。

この README は手で書いたものです。`tools/make_plain.py` で `.txt` を作り直して更新を再開したときは、この README の、どの時点の版かの記述も直してください。
