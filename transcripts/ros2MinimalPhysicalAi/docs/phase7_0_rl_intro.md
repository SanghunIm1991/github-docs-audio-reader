## 2. 強化学習の用語

### 2-1. 試行錯誤で方策を探す

強化学習では、コンピュータに、この状況ではこう動け、という正解を教えません。代わりに、動いた結果の良し悪しを、1つの数、つまり報酬で返します。コンピュータは、試しに動いては報酬を受け取ることを繰り返し、報酬の合計が大きくなる動き方を、少しずつ見つけていきます。子どもが自転車に乗れるようになるまで、転びながら、体の傾け方を覚えていくのに似ています。

このとき、試しに動くのがエージェント、エージェントが働きかける相手が環境です。エージェントは、環境の様子、つまり観測を見て、行動を決め、環境は行動を受けて、次の観測と報酬を返します。この1回のやり取りを、ステップと呼びます。

### 2-2. 用語と、車両と振り子との対応

表は4列で、8行あります。列は、用語、意味、車両、つまりフェーズ5 と6、そして振り子、つまりこのページです。

1行目はエージェントで、観測を見て行動を決めるものです。車両では PI 制御ノード、振り子では SAC が学習する NN です。

2行目は環境で、行動を受けて、次の状態に進むものです。車両では、フェーズ5-1 の疑似プラントと、フェーズ5-4 の Gazebo の物理、振り子では、Gymnasium の Pendulum-v1 です。

3行目は観測で、エージェントが見る、環境の様子です。車両では、目標速度と現在速度、振り子では、振り子の先の位置、つまりシータのコサインとサイン、そして角速度です。

4行目は行動で、エージェントが環境に与えるものです。車両では、マイナス1 から1 のペダルの指令、振り子では、マイナス2 から2 ニュートンメートルのトルクです。

5行目は報酬で、1ステップごとの良し悪しの数です。車両では、フェーズ6-3 の8節の案、たとえばマイナスの誤差などです。振り子では、真上からのずれ、角速度、トルクが小さいほど0 に近い、負の数です。

6行目はエピソードで、始めから終わりまでの1回の試行です。車両では、フェーズ6 の1回の記録、振り子では、10秒分の200ステップです。

7行目は方策、ポリシーで、観測から行動を決める規則です。車両では、PI 制御の式とゲイン、振り子では、観測3つからトルク1つを出す NN です。

8行目は収益、リターンで、1エピソードの報酬の合計です。将来の報酬ほど、少し割り引いて足すこともあります。車両の列は空欄で、振り子では、200ステップの報酬の合計です。

表の、方策の行が、フェーズ7 の核心です。PI 制御では、方策の形、つまり比例と積分の和を人が決め、中の数、つまりゲインだけを調整しました。強化学習では、方策を、NN のような、形を決めすぎない関数にし、その中の数、つまり重みを、報酬を手がかりに調整します。人が決めるのは、観測、行動、報酬の設計です。

### 2-3. エピソードの終わり方

エピソードの終わり方には、2種類あります。Gymnasium は、step の戻り値で、この2つを区別します。

terminated は、課題そのものが、成功または失敗で終わったことです。たとえば、倒立振子が倒れた、ゴールに着いた、です。

truncated は、課題とは関係なく、時間切れなどで打ち切ったことです。たとえば、決めたステップ数に達した、です。

フェーズ6 の記録でいえば、フェーズ6-1 の決めた時間で終わる記録は truncated、任意のフェーズ6-2 の、ゴールに着いたら終わる記録は terminated に当たります。学習のアルゴリズムは、この2つを区別して扱います。時間切れで打ち切っただけなら、その先も報酬が続いていたはずなので、この先の報酬は0、とみなしてはいけないからです。振り子には、倒れた、という失敗が無く、エピソードは常に、200ステップの時間切れ、つまり truncated で終わります。

### 2-4. このページで使うアルゴリズム、SAC

SB3 には、PPO、SAC、TD3 など、いくつものアルゴリズムがあります。このページでは、SB3 の公式の文書の SAC の例に倣い、SAC、Soft Actor-Critic を使います。SB3 の公式の文書は、連続値の行動、つまりトルクやペダルのように、とびとびでない値で、1つの環境を使って学習する場合、SAC や TD3 などを勧めています。SAC の特徴を、このページに要る範囲で、3つにまとめます。

1つ目。方策、つまり actor と、価値の見積もり、つまり critic の、2種類の NN を持ちます。critic は、この観測でこの行動をとると、この先どれだけの収益が見込めるかを見積もり、actor は、critic の見積もりが大きくなる行動を出すように学びます。学習の後、制御に使うのは actor だけです。

2つ目。経験をためて使い回します。これを off-policy と呼びます。過去のステップの、観測、行動、報酬、次の観測の組を、リプレイバッファにため、そこから取り出して学習します。同じ経験を何度も使えるので、少ないステップで学びやすくなります。

3つ目。行動にばらつきを持たせたまま学びます。学習中は、あえて行動を少しばらつかせて、まだ試していない行動も探します。これを探索と呼びます。ばらつきの大きさ、つまりエントロピーも、学習の中で自動で調整されます。評価や本番では、ばらつかせません。deterministic を True にする指定です。

### 3-1. 公式の例: でたらめな行動で CartPole を動かす

Gymnasium の公式の入門、Basic Usage の、Your First RL Program は、台車の上の棒を倒さないように保つ環境 CartPole-v1 を、でたらめな行動で、1エピソード動かす例です。原文は、この例を、そのまま抜粋して載せています。ただし、ウィンドウを見るための2行、つまり time を import する行と、env.close() の前に3秒待つ time.sleep の行を足し、足した行には、公式の例に追加、というコメントを付けています。この原稿では、抜粋のコードは写さず、原文の筆者がまとめた要点を読みます。ファイルは、ホームの rl_practice の cartpole_random.py です。

例の流れは、gym.make で、ウィンドウに表示する形で CartPole-v1 を作り、env.reset() で最初の観測を受け取って表示し、エピソードが終わるまで、でたらめな行動で env.step を繰り返して、報酬を足していく、というものです。最後に、報酬の合計を表示して、環境を閉じます。

公式の文書の説明の要点は、6つです。

1つ目。gym.make で環境を作ります。render_mode は表示の仕方で、human はウィンドウに表示、rgb_array は画像の配列を返し、指定しない、つまり None なら表示しません。表示しないのが最も速く、学習ではこれを使います。

2つ目。env.reset() で新しいエピソードを始め、最初の観測と、付加的な情報、つまり info を受け取ります。乱数の種、つまり seed を渡すと、同じ初期状態から始められます。

3つ目。env.step に action を渡して、行動を1回与え、次の観測、報酬、terminated、truncated、info の5つを受け取ります。これが1ステップです。

4つ目。env.action_space.sample() は、行動として許される範囲から、でたらめに1つ選びます。ここでは、エージェントの代わりに使っています。

5つ目。terminated か truncated の、どちらかが True になったら、エピソードは終わりです。次を始めるには、また reset します。

## 6. 自分で式を書いた制御器と比べる

### 6-1. 手書きの制御器

学習した方策と比べるために、振り子の運動方程式を知っている人が、自分で式を書いた制御器を用意します。Gymnasium のソースによると、振り子の角加速度は、15 かける シータのサイン に、3 かける トルクを足したものです。重力加速度が10、質量が1、長さが1 のときの値です。これを使って、次の2つを切り替えます。

1つ目。真上の近く、つまりシータのコサインが0.9 より大きいときは、PD 制御で立たせます。トルクは、10 かける シータ に、2 かける 角速度を足して、マイナスを付けたものです。フェーズ5-2 の PI 制御と同じく、ずれに比例する項と、変化の速さに比例する項、つまり D で戻します。D は、PI の I の代わりです。

2つ目。それ以外では、エネルギーを足して振り上げます。振り子の勢いを表す量、つまり2分の1 かける 角速度の2乗 に、15 かける シータのコサインを足したものが、真上で止まっているときの値の15 より小さければ、回っている向きにトルクをかけて、勢いを足します。

コードの数値、つまり PD 制御のゲインの kp イコール10 と kd イコール2、振り上げの係数の ke イコール1、切り替えの境目の0.9 は、筆者が目安として決めたもので、ほかの値と比べて選んだものではありません。ここでは、PD 制御のゲインを決めるときの一般的な考え方、つまり、どんな動きにしたいかを表す目標の値を先に決め、そこからゲインを逆算する、という考え方に照らして、kp と kd が妥当かを確かめます。

真上の近くの式です。真上の近くでは、シータのサインは、ほぼシータなので、角加速度は、15 かける シータ に、3 かける トルクを足したもので近似できます。ここに PD 制御のトルクを入れると、角加速度は、3 かける kp から15 を引いたものに シータを掛けたものと、3 かける kd に角速度を掛けたものを、どちらも引いた形になります。これは、ばねとダンパーにつないだおもりと同じ形の式で、ばねの強さに当たるのが、3 かける kp から15 を引いたもの、ダンパーの強さに当たるのが、3 かける kd です。この形の動きは、次の2つの数で決まります。

1つ目は、固有角振動数です。3 かける kp から15 を引いたものの平方根で、戻る速さの目安です。減衰が無いとしたときの揺れの角振動数で、単位は、毎秒ラジアンです。

2つ目は、減衰比です。3 かける kd を、2 かける 固有角振動数で割ったもので、揺れの収まりやすさです。1 以上で行き過ぎなし、0 に近いほど、揺れが続きます。

目標の値を決めてからゲインを選ぶとしたら、次の3つの順になります。コードの値は、この手順で決めたものではなく、後から、この手順に照らし合わせます。

1つ目は、倒れないこと、つまり kp の下限です。kp は5 より大きくします。そうしないと、シータにかかる係数が負にならず、重力に負けて倒れます。これは最低限の条件で、kp をいくつにするかは、次の2つの目標で決めます。

2つ目は、揺れの収まり方の目標で、減衰比を0.7 前後にします。真上から少しずれて止まった所から戻すとき、減衰比によって、動きは次のように変わります。上の形の式を、筆者が計算した値です。時間は、1 を固有角振動数で割ったものを1 とした値で、固有角振動数が毎秒4 ラジアンなら、0.25秒が1 に当たります。
