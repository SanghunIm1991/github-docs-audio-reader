### 2-1. 一次遅れの解と時定数

止まった状態、つまり F の d が0 から、アクセル u の a を踏み続けたときの駆動力は、上の一次遅れの式を解くと、次のようになります。F の d は、u の a かける F の d の max かける、1 マイナス、e の、マイナス t 割る タウ の a、乗。e は約2.718 で、自然対数の底です。e の右肩に乗る指数は、マイナス t 割る タウ の a です。

この解について、3つの点が書いてあります。

1つ目。t が タウ の a では、1 マイナス e の マイナス1 乗で、約0.63 になります。t が タウ の a の3倍では、1 マイナス e の マイナス3 乗で、約0.95 になります。フェーズ5-1 の2-2節の、時定数の時間で目標の約63パーセント、3倍の時間で約95パーセントに達する、は、ここから来ています。

2つ目。式の形を見ると、目標、つまり u の a かける F の d の max と、今の値の差が、時間とともに、e の マイナス t 割る タウ の a 乗の割合で縮んでいきます。力が、一定の値から別の値へ変わるときも、差が同じ形で縮みます。

3つ目。この解が式を満たすことは、微分して確かめられます。F の d を時間で微分すると、u の a かける F の d の max を タウ の a で割り、e の マイナス t 割る タウ の a 乗を掛けたものになります。両辺に タウ の a を掛けると、u の a かける F の d の max かける、e の マイナス t 割る タウ の a 乗、となり、これは、u の a かける F の d の max から F の d を引いたものに等しくなります。つまり、一次遅れの式と一致します。

### 2-2. 定常速度と、速度の時定数を手計算する

ペダルを u のまま踏み続けると、力が目標に達し、つまり F の d が u かける F の d の max、F の b が0 になり、やがて速度も変わらなくなります。つまり、v の時間による微分が0 です。運動方程式の左辺を0 にすると、そのときの速度、定常速度が求まります。定常速度 v の ss は、u かける F の d の max から ミュー m g を引いて、c で割ったもの、です。

既定値を入れると、次のようになります。

転がり抵抗の ミュー m g は、0.015 かける1500 かける9.81 で、約220.7ニュートンです。

ペダル0.5 では、定常速度は、0.5 かける3000 から220.7 を引いて、140 で割り、毎秒約9.14メートル、時速でおよそ33キロメートルです。

ペダル1.0、つまり全開では、毎秒約19.85メートル、時速でおよそ71キロメートルです。

ペダルが、220.7 割る3000 で、約0.074 より小さいと、駆動力が転がり抵抗に負けて、車両は動き出しません。

定常速度に近づく速さも、式から分かります。力が一定なら、運動方程式の両辺を c で割って整理すると、速度についての一次遅れと同じ形になります。m 割る c、かける、v の時間による微分、イコール、F の d から ミュー m g を引いて c で割ったもの、マイナス v、です。

2-1節の一次遅れの式と見比べると、m 割る c が時定数の位置にあり、F の d から ミュー m g を引いて c で割ったものが、目標、つまり定常速度の位置にあります。つまり、速度の時定数 T は、m 割る c で、1500 割る140、約10.7秒です。

ペダル0.5 を踏んでから、約11秒で定常速度の約63パーセント、つまり毎秒約5.8メートル、約32秒で約95パーセント、つまり約8.7メートルに達します。同じ時刻で比べると、この一次遅れの式の値、つまり9.14 かける、1 マイナス、e の マイナス t 割る10.7 乗、は、10秒で毎秒約5.56メートル、30秒で約8.58メートルで、フェーズ5-1 の4節の計算、つまり10秒で毎秒5.34メートル、30秒で8.55メートルとよく合います。計算のほうが少し遅れるのは、駆動力の立ち上がりにも、0.5秒の遅れがあるためです。

アクセルの遅れ、0.5秒は、この10.7秒に比べて短いので、ペダルを踏みっぱなしにしたときの速度の変化には、小さな影響しか与えません。アクセルやブレーキの遅れが効いてくるのは、ペダルを細かく踏み変えるとき、つまりフェーズ5-2 で、PI 制御がペダルを操作するときです。これは3-3節で扱います。

また、定常速度の式に、アクセルやブレーキの時定数は入っていません。時定数を変えると立ち上がりは遅れますが、最後に落ち着く速さは変わりません。フェーズ5-1 の6-3節で確かめた結果です。

### 2-3. オイラー法で、なめらかに計算できる条件

フェーズ5-1 の2-4節では、状態 x、つまり v と F の d と F の b を、刻み幅 デルタ t ごとに、オイラー法で進めました。k プラス1 回目の状態は、k 回目の状態に、デルタ t と、k 回目の変化率を掛けたものを足したもの、です。

オイラー法は簡単ですが、デルタ t が時定数に比べて長すぎると、計算が振動したり、発散したりします。これを、一次遅れの式、つまり タウ かける、x の時間による微分、イコール、x スター マイナス x、で確かめます。x スターは目標です。オイラー法の式に入れると、k プラス1 回目の x は、k 回目の x に、デルタ t 割る タウ と、x スターから k 回目の x を引いたものを掛けて、足したもの、になります。両辺から x スターを引くと、次の式になります。k プラス1 回目の、目標との差は、1 マイナス デルタ t 割る タウ、という倍率に、k 回目の、目標との差を掛けたもの、です。

1ステップごとに、目標との差が、1 マイナス デルタ t 割る タウ、の倍率で変わります。この倍率の符号と大きさで、計算の様子が決まります。

表は4列で、3行あります。列は、デルタ t と タウ の関係、倍率、目標との差の変わり方、計算の様子です。

1行目は、デルタ t が タウ より短いときです。倍率は0 から1 の間で、目標との差は、同じ符号のまま小さくなります。計算は、なめらかに目標へ近づき、正しい計算になります。

2行目は、デルタ t が、タウ より長く、2 タウ より短いときです。倍率はマイナス1 から0 の間で、目標との差は、符号が毎回入れ替わりながら小さくなります。計算は、目標をまたいで振動しながら近づきます。これは実物には無い振動です。

3行目は、デルタ t が2 タウ より長いときです。倍率はマイナス1 より小さく、目標との差は、符号が入れ替わりながら大きくなります。計算は発散し、値が際限なく大きくなります。

### 2-4. 抵抗を線形にした理由

フェーズ5-1 では、空気抵抗などをまとめて、速さに比例する抵抗、c かける v にしました。これは一般的なモデルから外れているので、その理由をまとめています。3つの点があります。

1つ目は、一般的なモデルです。空気抵抗は、速さの2乗に比例します。式は、2分の1、かける ロー、かける C の d かける A、かける v の2乗です。ローは空気の密度、C の d かける A は、車体の形と大きさで決まる値です。転がり抵抗は、速さによらず、ほぼ一定です。乗用車の最高の速度は、多くの場合、エンジンやモーターの出力、つまり力かける速さの上限で決まります。

2つ目は、このサンプルで線形にした理由です。速さに比例する抵抗にすると、運動方程式が線形の微分方程式になり、2-2節のように、定常速度と時定数を手計算で求められます。フェーズ5-1 の4節の計算の結果を、手計算と見比べられることを優先しました。係数 c は、このモデルに出力の上限が無い代わりに、アクセル全開の最高の速度を、毎秒約20メートルに収める役も担っています。そのため、本物の空気抵抗を線形にした値、つまり毎秒20メートルのあたりで、毎秒メートルあたり10ニュートン前後より、かなり大きく、速度が上がるほど増える抵抗、駆動系の損失なども含めたものを、まとめて1つの係数にしたもの、と考えます。

3つ目は、実務の目安です。車両の運動を実物に近づけたいときは、空気抵抗を2乗の式にし、駆動力に出力の上限、つまり速くなるほど出せる力が減る性質を入れます。制御器を設計するときには、逆に、ある速度の付近で線形に近づけたモデルを使うことが多い、とあります。線形のモデルなら、伝達関数などで解析できるためです。

## 3. PI 制御を読み解く、フェーズ5-2 の補足

フェーズ5-2 の2節の式を、ここに再び載せています。目標の速度を r、偏差を e、つまり r マイナス v とし、ペダルの指令 u、マイナス1 から1 の値を、比例ゲイン K の p と、積分ゲイン K の i で、次のように決めます。u イコール、K の p かける e、プラス、K の i かける、e を0 から t まで時間で積分したもの。計算した u が範囲を超えたら、端の値にそろえます。これを飽和と呼びます。

既定のゲインは、K の p が0.5、K の i が0.1 です。フェーズ5-2 の2-6節の値です。

### 3-1. P 制御だけでは偏差が残る

K の i が0、つまり P 制御だけの場合を考えます。速度が一定になったとき、2-2節の定常の式、つまり v の時間による微分が0 から、その速度 v を保つのに必要なペダル、u スターは、ミュー m g に c v を足して、F の d の max で割ったもの、になります。

毎秒10メートルを保つには、220.7 に140 かける10 を足して3000 で割り、u スターは約0.54 が必要です。ところが、P 制御では、u は K の p かける e なので、ペダルを0.54 踏み続けるには、e が、0.54 割る K の p、だけの偏差が残っていなければなりません。K の p が0.5 なら、毎秒約1メートルの偏差が残る計算になります。

正確には、u イコール K の p かける、r マイナス v、を定常の式に入れて v について解くと、P 制御で落ち着く速度は、次のようになります。分子は、K の p かける F の d の max かける r から、ミュー m g を引いたもの。分母は、c に、K の p かける F の d の max を足したもの。定常速度は、その分子を分母で割ったもの、です。

K の p が0.5、r が10 なら、分子は、0.5 かける3000 かける10 から220.7 を引いたもの、分母は、140 に1500 を足したもので、定常速度は毎秒約9.01メートルです。目標に届きません。K の p を大きくすれば偏差は小さくなりますが、0 にはなりません。フェーズ5-2 の4-2節の最後の課題2で、K の p を1.0 と2.0 に変えて確かめられます。

積分の項があると、偏差が残る限り、積分の項が増え続けるので、積分の項が u スター、つまり0.54 に達して、偏差が0 になったところで、ようやく変化が止まります。積分の項は、速度を保つのに必要な踏み込みを、自分で探し当てる役を担います。転がり抵抗や、速度に比例する抵抗の大きさを知らなくても、偏差を0 にできるのは、このためです。

### 3-2. ゲインの目安を式で求める

ゲインを当てずっぽうで探す前に、式で目安を立てます。アクセルの遅れを無視し、ペダルが範囲の端に達しない、つまり線形の範囲で考えると、運動方程式は、ペダル u から速度 v への、一次遅れになります。駆動力を u かける F の d の max とし、両辺を c で割ります。

式は、T かける、v の時間による微分、イコール、大文字の K かける u、マイナス v、プラス一定の項、です。ここで、大文字の K は、F の d の max 割る c で、毎秒約21.4メートル、T は、m 割る c で、約10.7秒です。

大文字の K は、ペダルを1 だけ踏み増したとき、最後に速度がどれだけ上がるか、を表し、T は、2-2節のプラントの時定数です。

一次遅れのプラントには、積分ゲイン K の i を、K の p 割る T に選ぶと、ループ全体が、次の時定数の一次遅れになる、という教科書的な選び方があります。プラントの遅れを、制御器の積分の項で打ち消すので、極零相殺と呼ばれます。この名前は、伝達関数で考えたときの言い方に由来します。この章では伝達関数を使わないので、名前だけを覚えておけばよい、とあります。

ループの時定数、T の c は、T を、大文字の K かける K の p で割ったもの、です。

K の p が0.5 なら、T の c は、10.7 を、21.4 かける0.5 で割って、約1.0秒、K の i は、0.5 割る10.7 で、約0.047 になります。プラントだけの時定数の10.7秒に比べて、約10倍速く、目標へ近づける計算です。

ただし、これは、ペダルが範囲の端に達しない、ということが前提です。目標を0 から毎秒10メートルへ一気に上げると、偏差10 に K の p の0.5 を掛けた5 は、上限の1 を大きく超え、しばらくペダルは全開に張り付きます。その間は、線形の式が成り立ちません。フェーズ5-2 の4節のシミュレーションで確かめると、K の i が0.047 では、目標のプラスマイナス2パーセントに収まるまでに、約24秒かかりました。ペダルが張り付いている間は積分を止めるので、張り付きが終わった後、積分の項が必要な0.54 まで育つのに時間がかかるのです。そこでフェーズ5-2 では、K の i を約2倍の0.1 にして、約14秒で収まるようにしました。

この選び方は、内部モデル制御、IMC、つまりプラントのモデルから制御器を組み立てる設計の方法にもとづく、PI の調整の決まりの、一次遅れのプラントの場合にあたります。これは、Rivera、Morari、Skogestad の1986年の論文の調整の決まりで、ラムダ調整と呼ばれることもあります。

その後、Skogestad は2003年に、プラントの時定数が、目指すループの時定数に比べて長い場合に、積分時間を T より短くする規則、SIMC 則を示しました。積分時間 T の i は、K の p 割る K の i です。積分時間を T のままにすると、外から加わる乱れ、つまり坂道や向かい風などの外乱による偏差を、打ち消すのが遅くなるためです。

SIMC 則では、タウ の c を、目指すループの時定数、つまり上の T の c にあたるもの、シータ を、むだ時間、つまりペダルを変えてから速度が動き始めるまでの遅れとして、次のように選びます。K の p は、T を、大文字の K かける、タウ の c プラス シータ、で割ったもの。積分時間 T の i は、T と、4 かける、タウ の c プラス シータ、の、小さい方です。

積分時間を縮めるのは、T が、4 かける、タウ の c プラス シータ、より長いときだけで、それ以外は、上の選び方、つまり T の i を T にするのと同じになります。この車両のモデルには、むだ時間がありません。つまり シータ は0 です。タウ の c を1.0秒とすると、K の p は、10.7 割る21.4 で0.5 となり、上と同じになります。T の i は、10.7 と4 の小さい方で4秒、K の i は、0.5 割る4 で0.125 になります。フェーズ5-2 で選んだ0.1 は、この値に近い、とあります。ただし、0.1 にした理由は、上のペダルの張り付きによる遅れで、SIMC 則が積分時間を短くする理由、つまり外乱の打ち消しとは違います。また、0.125 は、シミュレーションでは確かめていない、とあります。

このように、式で目安を立て、シミュレーションで確かめて調整するのが、ゲインを決めるふつうの流れです。

### 3-3. アクセルとブレーキで、ループの速さが変わる

3-2節の大文字の K は、アクセルの側の値です。ブレーキの側では、踏み切ったときの力が9000ニュートンなので、ブレーキの K、つまり F の b の max 割る c は約64.3 と、アクセルの約3倍になります。同じ K の p でも、減速するときは、ループが約3倍速く、つまり強く効きます。T の c の式の、大文字の K が3倍になるためです。

さらに、実際には、アクセルの0.5秒とブレーキの0.2秒の遅れがあります。ループが速く効くほど、この遅れの間に、行き過ぎやすくなります。ゲインを上げすぎると、ブレーキで減速しすぎてアクセルを踏み直し、また行き過ぎる、という振動が起きます。フェーズ5-2 の4-2節の後半の表の最後の行、つまり kp が5.0、ki が2.0 の場合と、フェーズ5-2 の6-2節の最後の課題1で確かめられます。アクセルとブレーキで時定数が違うこと、つまりフェーズ5-1 の2-2節が、ここで効いてきます。

同じ理由で、ブレーキの時定数を大きくする、つまりブレーキの効きを遅くすると、同じゲインでも、減速の段で、行き過ぎや下回りが大きくなります。フェーズ5-2 の6-5節で、時定数を変えて同じゲインで比べた結果は、この性質の表れです。

## 4. 動かした結果を読み解く、フェーズ5-3 と5-4 の補足

### 4-1. 目標0 で止まりきらない理由

フェーズ5-3 の5節では、目標を毎秒10、5、0 メートルと変えたとき、目標を0 にした後の様子を、表で示しました。時刻は、目標を0 にした時刻からの秒数です。

4列の表で、7行あります。列は、経過、速度、ペダル、積分の項です。

0秒では、速度が5.00、ペダルがマイナス1.00、積分の項が0.307 です。

1秒では、速度が0.62、ペダルがマイナス0.07、積分の項が0.242 です。

1.5秒では、速度が0.12、ペダルがプラス0.17、積分の項が0.229 です。

4秒では、速度が0.25、ペダルがプラス0.06、積分の項が0.181 です。

10秒では、速度が0.06、ペダルがプラス0.07、積分の項が0.101 です。

20秒では、速度が0.01、ペダルがプラス0.07、積分の項が0.076 です。

30秒より後では、速度が0.00、ペダルがプラス0.07、積分の項が0.074 です。

1.5秒ごろに毎秒0.12メートルまで下がった後、ペダルがアクセルの側に戻って、4秒ごろに0.25 まで浮き、その後20秒ほどかけて、ゆっくり0 へ近づきます。原因は、3-1節の積分の項の役割と、フェーズ5-1 の2-1節の、後ろへは進まない、つまり速度が0 を下回ったら0 にそろえる、の組み合わせにあります。流れは4つに分けて説明されています。

1つ目。目標が毎秒5メートルのとき、積分の項は、5メートルを保つのに必要な0.31 まで育っていました。3-1節の u スターの式で v を5 とすると、約0.31 です。目標が0 になっても、積分の項は、すぐには0 に戻りません。

2つ目。偏差、つまり目標から速度を引いたものは、速度が0 以上なので、0 以下にしかなりません。速度が小さくなると偏差も小さくなり、積分の項が減る速さ、つまり K の i かける偏差も遅くなります。

3つ目。比例の項は、速度が0 に近づくと0 に近づくので、ペダルは、積分の項の値、つまりプラスのアクセルに近づきます。そのアクセルで、車両がわずかに押し出されます。

4つ目。最後は、ペダルが0.074、つまり2-2節の、動き出さない境目に達したところで、駆動力と転がり抵抗がつり合って止まります。止まると偏差が0 になり、積分の項も0.074 のまま変わらなくなります。

PI 制御は、偏差を0 にするための仕組みで、止まる、後ろへは進まない、といった、式の外の決まりを知りません。そのため、ちょうど境目で止まるのは苦手です。実物の車両の制御では、目標が0 のときは積分の項を0 に戻してブレーキを踏ませる、といった、状況に応じた切り替えを、制御器の外側に足すことが多い、とあります。フェーズ5-3 の5節の最後の課題3で、この切り替えを試せます。

### 4-2. Gazebo の物理で、同じゲインの追いつき方が変わる理由

フェーズ5-4 の7節では、同じゲイン、つまり kp が0.5、ki が0.1 で、フェーズ5-3 の自作のプラントと、フェーズ5-4 の Gazebo の物理を比べました。

3列の表で、4行あります。列は、項目、フェーズ5-3 の自作のプラント、フェーズ5-4 の Gazebo の物理です。

目標10 での最高の速度は、フェーズ5-3 では10.00 で、行き過ぎはありません。フェーズ5-4 では10.31 で、約3パーセントの行き過ぎです。

10 で落ち着いたときのペダルは、フェーズ5-3 では0.54、フェーズ5-4 ではほぼ0 です。

目標5 での最低の速度は、フェーズ5-3 では5.00 で、下回りません。フェーズ5-4 では4.52 で、約10パーセント下回ります。

目標0 の後は、フェーズ5-3 では、毎秒0.25メートルほどまで浮き、約20秒かけて止まります。フェーズ5-4 では、約1秒で止まり、動きません。

理由は、プラントの車体の性質の違いにあります。4つに分けて説明されています。

1つ目は、抵抗がほとんど無いことです。自作のプラントには、転がり抵抗の約220ニュートンと、速度に比例する抵抗、毎秒10メートルで1400ニュートンがありました。Gazebo の車両の車輪と補助輪は、転がっても、抵抗をほとんど生みません。フェーズ5-4 の3-2節の実験では、一定のトルクで、加速度がほぼ一定のまま、速くなっても加速が鈍りませんでした。3-1節の u スターの式で、抵抗を0 にすると、u スターは0 になるので、一定の速さを保つのに力が要らず、落ち着いたペダルも積分の項も、0 に近づきます。

2つ目は、目標0 で止まることです。4-1節で見たとおり、自作のプラントで止まりきらなかったのは、速度を保つのに要った積分の項、0.31 が残っていたからでした。Gazebo の車両では、もともと積分の項が0 に近いので、残りが無く、ブレーキで止まったまま動きません。

3つ目は、行き過ぎと下回りです。抵抗が無いと、ペダルを戻しても、車両は勢いのまま進み続けます。自作のプラントでは、抵抗が、自然にブレーキの役をしていました。さらに、オドメトリの速度は、直近の10回分、つまり0.2秒分の平均なので、実際の速度より少し遅れて届きます。フェーズ5-4 の2-1節の表の話です。遅れて届く速度で制御すると、行き過ぎやすくなります。

4つ目は、ゲインの意味が変わることです。3-2節で、ゲインの目安は、プラントを一次遅れに近づけて考えることから求めました。抵抗が無いプラントは、2-2節の時定数、T イコール m 割る c の c が0 に近づき、時定数が際限なく長くなります。一次遅れではなく、力の積み重ねで速度が決まる、積分の形になるので、同じゲインが最適ではなくなります。

フェーズ5-4 の7節の最後の課題4、つまり抵抗をほぼ0 にしたプラントで、フェーズ5-2 の closed_loop_sim.py を使って同じ比べをする課題で、抵抗が無いことが違いの主な理由だと確かめられます。

## 5. まとめ

まとめは6つです。

1つ目。一次遅れの式は、目標との差が、e の マイナス t 割る タウ 乗の割合で縮む形をしています。時定数の時間で約63パーセント、3倍で約95パーセントに達します。

2つ目。抵抗を線形にした車両のモデルは、速度についても一次遅れになり、定常速度、つまり、u かける F の d の max から ミュー m g を引いて c で割ったものと、時定数、つまり m 割る c を、手計算で求められます。

3つ目。オイラー法では、1ステップごとに、目標との差が、1 マイナス デルタ t 割る タウ、の倍率で変わります。刻み幅が時定数より長いと振動し、2倍より長いと発散します。

4つ目。P 制御だけでは、速度を保つのに要る踏み込みの分だけ、偏差が残ります。積分の項は、その踏み込みを自分で探し当てて、偏差を0 にします。

5つ目。ゲインの目安は、プラントを一次遅れに近づけて、式で求められます。極零相殺では、K の i を K の p 割る T にし、ループの時定数は、T を、大文字の K かける K の p で割ったものです。ペダルが張り付く範囲では式が成り立たないので、シミュレーションで確かめて調整します。

6つ目。フェーズ5 で見た、目標0 で止まりきらないことと、Gazebo の物理で行き過ぎることは、どちらも、積分の項が覚えている値と、プラントの抵抗の有無で説明できます。式が成り立つ前提、つまり線形であること、抵抗があること、後ろへ進まないこと、などを意識すると、ゲインがどこで効かなくなるかを予想できます。
