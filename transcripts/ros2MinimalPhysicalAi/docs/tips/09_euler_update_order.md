# Tips集 9: オイラー法の更新の順番、力を先に更新しないのはなぜか（聞くための原稿）

これは、ros2MinimalPhysicalAi という教材の、Tips集の9つ目の項目です。

Tips集は、手順書、つまりフェーズの本文に入れると流れが途切れる、分量の少ない補足をまとめた資料です。どの項目も独立しているので、関係する手順書を読んでいるときや、疑問を持ったときに、その項目だけを読めばよい、とあります。

対象は、ROS2 Jazzy と Ubuntu 24.04 です。版に依存する記述は、この資料を作ったときに、/opt/ros/jazzy と Ubuntu のパッケージに入っていたもので確かめた、とあります。所要の目安は、1項目あたり5 から15分の読み物です。

この項目に関係する手順書は、車両の疑似プラントを扱う、フェーズ5-1 の2-4節と4節です。フェーズ7-1 以降も、同じモデルを使います。

出どころについて、断りがあります。この資料の内容は、/opt/ros/jazzy のソースなどを読んで確かめ、自分の言葉で書いたもので、ソースやドキュメントの転載ではない、とあります。9節は、数値計算の一般的な内容を、自分の言葉で書いたもの、とあります。9-3節の数値は、2026年10月12日に計算したもので、計算の仕方は、本文の9-3節で述べています。

## 9. オイラー法の更新の順番、力を先に更新しないのはなぜか

### 9-1. 疑問: 力を更新してから、速度を進めるべきではないか

フェーズ5-1 の、車両の疑似プラントの step は、駆動力、制動力、速度の3つの変化率を、どれも区間の始めの値から求め、その後で、3つをまとめて進めます。フェーズ5-1 の2-4節の、オイラー法です。直観的には、先に力を新しい値に更新し、その力で、区間の速度の変化を計算するほうが、正しく見えます。

### 9-2. 区間の中で、力も変わり続けている

プラントの式は、駆動力 F の d と、速度 v が、どちらも時間とともに連続して変わる、微分方程式です。0.01秒の区間の中でも、力は、区間の始めの値から終わりの値へ、少しずつ変わっています。速度の本当の変化量は、区間の中で変わり続ける力を積み重ねたもの、つまり積分なので、区間の始めの力も、終わりの力も、区間全体を代表する本当の力ではありません。本当の値は、その間にあります。

表は3列で3行です。列は、計算の仕方と、区間の中の力を何で代表させるか、名前、です。

1行目は、フェーズ5-1 のコード、つまりまとめて進める形です。区間の始めの力で代表させます。名前は、前進オイラー法、または陽的オイラー法です。

2行目は、力を先に更新してから、速度を進める形です。区間の終わりの力で代表させます。名前は、半陰的オイラー法です。ばねと質量の系で、シンプレクティック・オイラー法と呼ばれるものと、同じ考え方です。

3行目は、始めと終わりの平均を使う形です。2つの間の力で代表させます。台形則の考え方です。

力を先に更新する形も、区間の終わりの力が、区間の始めから働いていたことにするので、近似であることに変わりはありません。加速するとき、つまり力が増えていくときは、始めの力を使うと控えめに、終わりの力を使うと多めに見積もります。ブレーキを踏むときは、力を先に更新するほうが、ブレーキが早く効いたように計算されます。

### 9-3. 実際の差は小さく、刻み幅を小さくすると、どちらも同じ答えに近づく

フェーズ7-1 の、ブレーキの遅いプラント、つまり tau_brake が1.0秒のプラントで、アクセル0.5 を30秒踏んだ後に、ブレーキ0.3 を踏む場合を計算しました。刻み幅0.01秒で、2通りの順番で計算し、刻み幅を10万分の1秒にした計算と比べています。10万分の1秒の計算は、真の値の代わりです。この資料を作ったときに、フェーズ5-1 の式を写した、小さな Python のスクリプトで計算した、とあります。

表は4列で4行です。列は、時刻、真の値、フェーズ5-1 のコードの誤差、力を先に更新した誤差、です。

1行目は、1秒です。真の値は毎秒0.413メートルです。フェーズ5-1 のコードの誤差は、マイナス0.0004、力を先に更新した誤差は、プラス0.0064 です。誤差の単位も、毎秒メートルです。

2行目は、5秒です。真の値は毎秒3.082メートル、フェーズ5-1 のコードの誤差はプラス0.0018、力を先に更新した誤差はプラス0.0074 です。

3行目は、31秒、つまりブレーキの1秒後です。真の値は毎秒7.414メートル、フェーズ5-1 のコードの誤差はプラス0.0046、力を先に更新した誤差はマイナス0.0139 です。

4行目は、32秒です。真の値は毎秒5.346メートル、フェーズ5-1 のコードの誤差はプラス0.0015、力を先に更新した誤差はマイナス0.0204 です。

表の後に、説明が3つあります。

1つ目。どちらの誤差も、最大で毎秒約0.02メートルと、小さいです。速度に対する割合は、走り出しの1秒の時点の、力を先に更新した形が最も大きく、約1.5パーセントです。速度そのものが小さいためです。それ以外は、1パーセント未満です。フェーズ6-3 の指標や、フェーズ7-1 の報酬には、ほとんど響かない、とあります。

2つ目。刻み幅を、0.02秒、0.01秒、0.005秒と半分にしていくと、32秒の時点の誤差は、どちらも半分ずつになります。フェーズ5-1 のコードでは、毎秒0.0029、0.0015、0.0007メートルです。力を先に更新した形では、毎秒0.041、0.020、0.010メートルです。2つは、同じ精度、つまり1次の精度の近似です。

3つ目。この例では、フェーズ5-1 のコードの誤差のほうが小さかったが、一般に勝つとは言えない、とあります。速度に比例する抵抗の項も、区間の始めの速度で計算しているため、その誤差が、力の遅れの誤差と逆向きに打ち消し合った面が大きい、と考えられる、とあります。項目ごとに分けて計算して確かめてはいない、とあります。

### 9-4. フェーズ5-1 が、まとめて進める形にしている理由

理由は2つです。

1つ目は、式の並びの順番に、結果が左右されないことです。今の状態から、全部の変化率を求め、そろって進める形は、状態がいくつあっても、書き方が同じです。順番に更新する形では、どの状態を先に書き換えるかで結果が変わり、式を足したり並べ替えたりしたときに、意図せず結果が変わることがあります。

2つ目は、教科書のオイラー法の定義そのものなので、フェーズ5-1 の2-4節の安定性の説明と、そのまま対応することです。刻み幅が時定数の2倍より長いと発散する、という説明です。

### 9-5. 力を先に更新する形が好まれる場面と、精度を上げる方法

ばねと質量のように揺れ続ける系では、速度を先に更新し、その新しい速度で位置を進める、半陰的オイラー法のほうが、エネルギーが勝手に増えたり減ったりしにくいので、物理シミュレーションでよく使われます。フェーズ5-1 の車両は、一次遅れと抵抗だけの、揺れずに落ち着く系なので、この利点は、ほぼ表に出ません。

精度を上げたいときは、刻み幅を小さくするか、台形則やルンゲ・クッタ法のような、高い次数の方法を使います。一次遅れの式だけなら、正確な解、つまり指数関数で、1ステップ進めることもできます。
