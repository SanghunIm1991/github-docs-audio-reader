# シミュレータ（聞くための原稿）

これは、ロボットの学習と開発に使われる、シミュレータについての話です。

シミュレータは、仮想の空間でロボットを動かし、練習や試験をするためのソフトウェアです。実物のロボットでは時間がかかったり、壊れる心配があったりする試行を、計算機の中で大量に、安全に繰り返せます。原文のファイルでは、ロボットの学習と開発に使われる代表的なシミュレータを、開発元や用途が偏らないように選んで整理しています。特定のツールを勧めるものではなく、並びの順は後で説明する分類の順で、優劣を表しません。

## 選び方と、今回は載せていないもの

選び方はこうです。後で説明する3つの分類のそれぞれから、別の系統のツールを選び、同じ開発元のものは1つの項目にまとめました。例えば、MuJoCo Playground は MuJoCo に、Isaac Lab は Isaac Sim に含めています。

ただし Newton は、MuJoCo の開発元である Google DeepMind と、Isaac の開発元である NVIDIA が、Disney Research とともに始めたプロジェクトなので、開発元は一部で重なっています。また、「開発・試験」の分類の O3DE は、元のリポジトリのテーマである RAI の開発元が、デモと評価に使っていることから選びました。

今回は載せていないものもあります。CPU だけで動かすことを主にしたシミュレータや、屋内の移動やナビゲーションの研究向けのシミュレータなどの系統です。次の更新で追加を検討するとしています。そのため今の一覧は、GPU で多数の試行を並列に回す系統の割合が多くなっています。

## シミュレータの分類と選ぶときの観点

ロボットのシミュレータは、大まかに3つの層に分けられます。1つのツールが複数の層にまたがることも、別の層のツールを中で使うこともあります。

原文では、これを3行の表にまとめています。表の列は、分類、何をするか、このファイルの項目、の3つです。

1行目は、物理エンジンです。物体の動き、接触、関節の力を計算する、中核の部分です。このファイルの項目では、MuJoCo と Newton がここに入ります。

2行目は、ロボット学習の環境です。物理エンジンの上に、学習用の課題、ロボットのモデル、センサー、学習の仕組みを載せ、多数の試行を並列に回します。Isaac Sim と Isaac Lab、ManiSkill、Genesis World がここに入ります。

3行目は、ロボットのソフトウェアの開発と試験です。ROS 2 などで作ったロボットのソフトウェアを、センサーや環境ごと仮想の空間で動かして確かめます。Gazebo と O3DE がここに入ります。Isaac Sim も、この用途を備えています。

これらの層は、組み合わせて使われます。例えば、Newton は MuJoCo の GPU 版である MuJoCo Warp を、主な計算の部分に使っています。Isaac Lab は、計算の部分として、Newton や Isaac Sim などを切り替えて使えます。Gazebo も、複数の物理エンジンを使い分けられます。ですから、「どれか1つを選ぶ」というより、「どの層に何を使うか」を考えることになります。

選ぶときの観点は3つです。

1つ目は目的です。強化学習や模倣学習のために大量の試行を回したいのか、ROS 2 のソフトウェアを試験したいのか、です。

2つ目は、使える計算機です。このファイルの項目のうち、GPU で並列に回す機能の多くは、NVIDIA の GPU を前提にしています。それ以外の GPU に対応するものもあり、各項目の状態の注記に書かれています。

3つ目はライセンスです。本体のライセンスと、付属のロボットのモデル、3D データ、依存するソフトウェアの利用条件が、別になっていることがあります。商用に使う場合は、特に確かめてください。

## OSS: MuJoCo

MuJoCo は、関節を持つ物体どうしの動きと接触を、速く正確に計算することを狙った物理エンジンです。README が引用を求めている論文は、2012年の国際会議 IROS のものです。現在は Google DeepMind が保守しています。

C 言語の API を中心に、Python から使う仕組みと、Unity 向けの部品があります。GPU で動かす版として、JAX で書かれた MJX と、MuJoCo Warp があります。

その上に作られた MuJoCo Playground は、歩行や物を扱う作業などの学習用の環境をそろえ、シミュレータで学んだ動きを実機に移す、sim-to-real までを扱います。開発元の論文によれば、四脚、人型、ロボットハンド、ロボットアームで、実機に移しました。

ライセンスは、ソースコードが Apache-2.0、ドキュメントが CC BY 4.0 です。MuJoCo Playground も Apache-2.0 ですが、地形の画像の一部は除かれます。

状態は実用です。正式なリリースが続いていて、開発元は毎月の第1週に出すことを目標にしています。確認した時点の最新の版は、2026年10月14日の 3.16.0 です。README に、研究用や試験的といった注意書きはありません。

一次情報は、MuJoCo と MuJoCo Playground の公式のリポジトリと、MuJoCo Playground の論文です。

## OSS: Newton

Newton は、GPU で動く物理エンジンで、ロボットの研究者と開発者を対象にしています。Disney Research、Google DeepMind、NVIDIA が始め、現在は Linux Foundation のプロジェクトとして、コミュニティで開発と保守がされています。

NVIDIA の Warp の上に作られています。Warp は、GPU の計算を Python で書く仕組みです。そして、主な計算の部分に MuJoCo Warp を組み込んでいます。

特徴として3つを挙げています。3D のシーンの共通の形式である OpenUSD に対応すること。計算の結果を微分できるので、学習に使いやすいこと。利用者が機能を足せること。また、Isaac Lab の計算の部分としても使えます。

ライセンスは、コードが Apache-2.0、ドキュメントが CC BY 4.0 です。

状態は実用です。正式なリリースが続いていて、確認した時点の最新の版は、2026年10月14日の 1.7.0 です。README に、研究用や試験的といった注意書きはありません。ただし、GPU での計算には NVIDIA の GPU が要ります。macOS では、CPU だけで動きます。

一次情報は、公式のリポジトリです。

## OSS: Isaac Sim と Isaac Lab

Isaac Sim と Isaac Lab は、NVIDIA のシミュレータです。

Isaac Sim は、NVIDIA の Omniverse の上で動くアプリケーションで、写実的な仮想の環境で、ロボットを開発し、試験し、学習させます。URDF、MJCF、CAD などの形式からロボットを読み込めます。また、センサーの模擬、ROS とつなぐ仕組み、学習用のデータを人工的に作る道具を備えています。

Isaac Lab は、強化学習や模倣学習などのロボット学習のための、GPU で並列に回す枠組みです。開発元の論文によれば、Isaac Gym の後継にあたります。腕、四脚、人型などのロボットのモデルと、すぐに学習を始められる環境をそろえています。Isaac Lab は計算の部分を、Newton や Isaac Sim などに切り替えられるので、すべての使い方で Isaac Sim が要るわけではありません。なお、Isaac Lab での開発の詳しい話は、元のリポジトリの Isaac Lab のファイルにまとめられています。

ライセンスには注意が要ります。Isaac Sim のリポジトリのソフトウェアは Apache-2.0 です。ただし、作ったり使ったりするには、Omniverse Kit SDK や 3D モデルなど、NVIDIA の別の条件の部品が要ります。Isaac Lab は BSD-3-Clause で、一部の拡張は Apache-2.0 です。Isaac Sim と組み合わせて使う場合は、Isaac Sim 側の条件もかかわります。

状態は実用です。Isaac Sim は正式なリリースが続いていて、確認した時点の最新の版は、2026年10月14日の 6.2.0 です。Isaac Lab の正式な版の最新は、2026年2月2日の 2.3.2 です。次の 3.0 は、2026年9月16日の 3.0.0-EA という先行の版の段階です。Isaac Sim の README が示す GPU の要件は、NVIDIA の GPU で、ワークステーションでは RTX 4080 以上です。

一次情報は、Isaac Sim と Isaac Lab の公式のリポジトリと、Isaac Lab の論文です。

## OSS: ManiSkill

ManiSkill は、物を扱う作業、つまりマニピュレーションに重点を置いた、ロボットのシミュレーションと学習の枠組みです。物理と描画には SAPIEN を使います。

GPU で多数の環境を並列に動かせて、並列の環境ごとに、別の物体や場面を置くこともできます。強化学習、模倣学習、VLA の比較用の手法、つまりベースラインを用意しています。また、実機で学んだ方策をシミュレータの中で評価する環境、いわゆる real2sim と、シミュレータで学んだ方策を実機に移す例も用意しています。現在の版である ManiSkill3 の論文は、国際会議 RSS 2025 で発表されました。

ライセンスは、リポジトリが Apache-2.0 です。開発元によれば、剛体の環境はすべて、Apache-2.0 などの制限の少ないライセンスです。ただし、付属のアセット、つまり 3D のデータなどは、CC BY-NC 4.0 で、非営利に限られます。

状態は実用です。正式な版の 3.0 が出ていて、確認した時点の最新の版は、2026年4月21日の 3.0.1 です。README に、研究用や試験的といった注意書きはありません。ただし、GPU での並列の計算は、開発元によれば、Linux と NVIDIA の GPU の組み合わせでだけ使えます。

一次情報は、公式のリポジトリと論文です。

## OSS: Genesis World

Genesis World は、フィジカルAIの開発のためのシミュレーションの基盤です。旧名は Genesis です。開発元によれば、2024年12月に研究のプロジェクトとして始まり、現在は Genesis AI という企業が開発を支えています。

3つの要素を、Python の使いやすい窓口でまとめています。1つ目は、剛体だけでなく、柔らかい物体、砂、液体、布などを、1つの場面で一緒に計算する物理エンジン。2つ目は、自前の描画の仕組み。3つ目は、Python で書いた計算を各種の計算機向けに変換する仕組みで、名前は Quadrants です。

開発元によれば、変換の先は NVIDIA の GPU、つまり CUDA に限りません。AMD の GPU の ROCm、Apple の GPU の Metal、Vulkan、一般の CPU にも対応します。

ライセンスは、ソースコードが Apache-2.0 です。

状態は実用です。正式な版の 1.x が出ていて、確認した時点の最新の版は、2026年10月11日の 1.4.4 です。README に、研究用や試験的といった注意書きはありません。

一次情報は、公式のリポジトリです。

## OSS: Gazebo

Gazebo は、オープンソースのロボットのシミュレータです。現在の Gazebo は、旧来の Gazebo Classic を引き継いだもので、開発元によれば、16年以上の開発の蓄積があります。

複数の物理エンジンを使い分けられます。また、レーザー距離計、カメラ、IMU、GPS などのセンサーを、雑音のモデルつきで模擬できます。

ROS、これは ROS 2 を含みますが、その ROS とつなぐためのパッケージ ros_gz を、同じ開発元が公開しています。そのため、ROS 2 で作ったロボットのソフトウェアを、仮想の空間で動かして確かめる用途に向いています。

版には名前がついています。確認した時点の最新は、2025年9月の Jetty で、2031年5月までの長期の保守の対象です。

ライセンスは Apache-2.0 で、状態は実用です。

一次情報は、Gazebo Sim の公式のリポジトリ、ROS とつなぐパッケージ ros_gz、公式の版の一覧です。

## OSS: O3DE

O3DE は、Open 3D Engine の略です。ゲーム、映像、シミュレーションを作るための、オープンソースの 3D エンジンです。企業が Open 3D Foundation の会員として、開発を支えています。

ロボットの用途では、ROS 2 とつなぐ部品が、追加の部品集の o3de-extras で提供されています。部品の名前は ROS2 の Gem で、センサー、制御、ロボットのモデルの読み込みなどを扱います。

元のリポジトリの RAI とのつながりもあります。RAI の開発元のデモ、agentic-mobile-manipulator は、ROS 2、O3DE、RAI の組み合わせで作られています。また、RAI のベンチマークにも O3DE を使うものがあり、外部の論文 RHO の評価に使われた例があります。

ライセンスは、Apache-2.0 か MIT のどちらかを、利用者が選べます。第三者の部品は、それぞれの条件に従います。

状態は実用です。正式なリリースが続いていて、確認した時点の最新の版は、2026年5月27日の 2605.0 です。

一次情報は、公式のリポジトリ、ROS 2 とつなぐ部品を含む o3de-extras、公式サイトです。

## 論文: A Survey: Learning Embodied Intelligence from Physical Simulators and World Models

これは、物理シミュレータと世界モデルを、身体を持つ AI を学ばせる2つの道具として並べて論じた、総説の論文です。2025年7月に arXiv に投稿され、2025年9月に改訂されました。

外にある仮想の練習場と、ロボットが内に持つ予測の仕組みを組み合わせることで、シミュレータで学んだことを実世界に持ち出しやすくなる、という見方で研究を整理しています。関連する論文とオープンソースの一覧も、著者らのリポジトリで公開されています。原文では、特定のツールに寄らずに全体を見渡す入り口として載せています。

ライセンスは、arXiv の掲載ページの表示によれば CC BY 4.0 です。状態は研究段階です。

## まとめ

シミュレータは、物理エンジン、ロボット学習の環境、ロボットのソフトウェアの開発と試験、という3つの層に分けられ、実際には層を組み合わせて使います。

物理エンジンでは MuJoCo と Newton を、学習の環境では Isaac Sim と Isaac Lab、ManiSkill、Genesis World を、開発と試験では Gazebo と O3DE を紹介しました。全体を見渡す入り口として、総説の論文も1つ紹介しました。

選ぶときは、目的、使える計算機、ライセンスを見ます。NVIDIA の GPU が前提のものが多いこと、そして、Isaac Sim や ManiSkill のように、付属の部品やデータに別の条件があるものがあることに、注意してください。
