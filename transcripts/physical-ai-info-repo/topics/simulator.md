# シミュレータ（聞くための原稿）

これは、ロボットの学習と開発に使われる、シミュレータについての話です。代表的なものを8つ紹介します。情報は、どれも2026年10月17日の時点で確かめたものです。紹介する順は分類の順で、どれが優れているかを表すものではありません。

この話のポイントは3つです。

1つ目。シミュレータは、物理エンジン、ロボット学習の環境、ロボットのソフトウェアの開発と試験、という3つの層に分けて考えると整理しやすく、実際には層を組み合わせて使います。

2つ目。選ぶときは、目的、使える計算機、ライセンスの3つを見ます。特に、GPU で並列に回す機能の多くは、エヌビディアの GPU を前提にしています。

3つ目。紹介する7つのオープンソースは、どれも実用の段階にあります。ただし、本体と付属のデータでライセンスが違うものがあるので、商用に使うときは注意が要ります。

## まず、シミュレータとは何か、そして、どう選んだかについてです

シミュレータは、仮想の空間でロボットを動かし、練習や試験をするためのソフトウェアです。実物のロボットだと時間がかかったり、壊れる心配があったりする試行を、計算機の中で大量に、安全に繰り返せます。

紹介するものは、開発元や用途が偏らないように選びました。後で説明する3つの分類のそれぞれから、別の系統のツールを選び、同じ開発元のものは1つにまとめています。例えば、ムジョコ・プレイグラウンドはムジョコに、アイザック・ラボはアイザック・シムに含めました。ただし、ニュートンは、ムジョコの開発元のグーグル・ディープマインドと、アイザックの開発元のエヌビディアが、ディズニー・リサーチとともに始めたものなので、開発元は一部で重なっています。また、オー・スリー・ディー・イーは、アール・エー・アイの開発元がデモと評価に使っていることから選びました。

今回は、CPU だけで動かすことを主にしたシミュレータや、屋内の移動の研究向けのシミュレータは載せていません。そのため、今の顔ぶれは、GPU で多数の試行を並列に回す系統が多くなっています。

## 次は、シミュレータの3つの分類と、選ぶときの観点についてです

ロボットのシミュレータは、大まかに3つの層に分けられます。

1つ目の層は、物理エンジンです。物体の動き、接触、関節の力を計算する、中核の部分です。ここにはムジョコとニュートンが入ります。

2つ目の層は、ロボット学習の環境です。物理エンジンの上に、学習用の課題、ロボットのモデル、センサー、学習の仕組みを載せ、多数の試行を並列に回します。ここにはアイザック・シムとアイザック・ラボ、マニスキル、ジェネシス・ワールドが入ります。

3つ目の層は、ロボットのソフトウェアの開発と試験です。ロス・ツーなどで作ったソフトウェアを、センサーや環境ごと仮想の空間で動かして確かめます。ここにはガゼボとオー・スリー・ディー・イーが入ります。アイザック・シムも、この用途の機能を備えています。

これらの層は、組み合わせて使われます。例えば、ニュートンはムジョコの GPU 版を計算の中心に使っています。アイザック・ラボは、計算の部分としてニュートンやアイザック・シムなどを切り替えて使えます。ガゼボも複数の物理エンジンを使い分けられます。ですから、どれか1つを選ぶというより、どの層に何を使うかを考えることになります。

選ぶときの観点は3つです。1つ目は目的で、強化学習や模倣学習のために大量の試行を回したいのか、ロス・ツーのソフトウェアを試験したいのか、です。2つ目は使える計算機で、ここで紹介するもののうち、GPU で並列に回す機能の多くは、エヌビディアの GPU を前提にしています。ただし、ほかの GPU に対応するものもあります。3つ目はライセンスで、本体と、付属のロボットのモデルや 3D データ、依存するソフトウェアの利用条件が、別になっていることがあります。商用に使う場合は、特に確かめてください。

## 次は、物理エンジンを2つ紹介します

1つ目は、ムジョコです。関節を持つ物体どうしの動きと接触を、速く正確に計算することを狙った物理エンジンで、元になった論文は2012年の国際会議のものです。今はグーグル・ディープマインドが保守しています。C 言語の API を中心に、パイソンから使う仕組みや、ユニティ向けの部品があります。GPU で動かす版も2つあります。その上に作られたムジョコ・プレイグラウンドは、歩く、物を扱うといった学習用の環境をそろえ、シミュレータで学んだ動きを実機に移すところまでを扱います。開発元の論文によれば、四本脚のロボット、人型ロボット、ロボットハンド、ロボットアームで、実機に移すことができました。正式なリリースが続いていて、開発元は毎月の最初の週に出すことを目標にしています。

2つ目は、ニュートンです。GPU で動く物理エンジンで、ロボットの研究者と開発者を対象にしています。ディズニー・リサーチ、グーグル・ディープマインド、エヌビディアが始め、今はリナックス・ファウンデーションのプロジェクトとして、コミュニティで開発されています。エヌビディアのワープという、GPU の計算をパイソンで書く仕組みの上に作られ、計算の中心にムジョコの GPU 版を組み込んでいます。特徴として、3D のシーンの共通の形式であるオープン・ユーエスディーに対応すること、計算の結果を微分できるので学習に使いやすいこと、利用者が機能を足せること、を挙げています。アイザック・ラボの計算の部分としても使えます。正式なリリースが続いていますが、GPU での計算にはエヌビディアの GPU が要ります。なお、マックでは CPU だけで動きます。

## 次は、ロボット学習の環境を3つ紹介します

1つ目は、エヌビディアの、アイザック・シムとアイザック・ラボです。

アイザック・シムは、エヌビディアのオムニバースという基盤の上で動くアプリケーションで、写実的な仮想の環境で、ロボットを開発し、試験し、学習させます。いろいろな形式のファイルからロボットを読み込め、センサーの模擬、ロスとつなぐ仕組み、学習用のデータを人工的に作る道具を備えています。

アイザック・ラボは、強化学習や模倣学習などのための、GPU で並列に回す枠組みです。開発元の論文によれば、以前のアイザック・ジムの後継にあたります。腕、四本脚、人型などのロボットのモデルと、すぐに学習を始められる環境をそろえています。計算の部分は切り替えられるので、どの使い方でもアイザック・シムが要るわけではありません。

注意したいのはライセンスです。アイザック・シムのリポジトリのソフトウェア自体はオープンソースですが、作ったり使ったりするには、エヌビディアの別の条件の部品が必要です。アイザック・ラボを、アイザック・シムと組み合わせて使う場合は、アイザック・シム側の条件もかかわります。また、アイザック・シムの説明書きが示す GPU の要件は、エヌビディアの GPU で、ワークステーションでは RTX 4080 以上です。アイザック・シムは正式なリリースが続いています。アイザック・ラボは、次の大きな版がまだ先行公開の段階です。

2つ目は、マニスキルです。物を扱う作業、いわゆるマニピュレーションに重点を置いた、シミュレーションと学習の枠組みです。物理と描画には、サピエンという仕組みを使います。GPU で多数の環境を並列に動かせて、並列の環境ごとに、別の物体や場面を置くこともできます。比べるための基準になる手法や、実機で学んだ動きをシミュレータの中で評価する環境、シミュレータで学んだ動きを実機に移す例も用意しています。今の版の論文は、2025年の国際会議で発表されました。注意点は2つです。付属の 3D のデータなどは、非営利に限るライセンスです。また、GPU での並列の計算は、開発元によれば、リナックスとエヌビディアの GPU の組み合わせでだけ使えます。

3つ目は、ジェネシス・ワールドです。フィジカルAIの開発のための、シミュレーションの基盤で、以前はジェネシスという名前でした。開発元によれば、2024年12月に研究のプロジェクトとして始まり、今はジェネシス・エーアイという企業が開発を支えています。硬い物だけでなく、柔らかい物、砂、液体、布などを、1つの場面で一緒に計算する物理エンジンと、自前の描画の仕組み、パイソンで書いた計算をいろいろな計算機向けに変換する仕組みを、まとめて使いやすくしています。開発元によれば、変換の先は、エヌビディアの GPU に限らず、エーエムディーやアップルの GPU、一般の CPU にも対応します。

## 次は、ロボットのソフトウェアの開発と試験に使うものを2つ紹介します

1つ目は、ガゼボです。オープンソースのロボットのシミュレータで、旧来の版を引き継いだもので、開発元によれば16年以上の開発の蓄積があります。複数の物理エンジンを使い分けられ、レーザーで距離を測るセンサー、カメラ、動きを測るセンサー、GPS などを、雑音も含めて模擬できます。ロス・ツーとつなぐための部品を同じ開発元が公開していて、ロス・ツーで作ったソフトウェアを、仮想の空間で動かして確かめる用途に向いています。版には名前がついていて、確認した時点の最新の版は、2031年5月までの長期の保守の対象です。

2つ目は、オー・スリー・ディー・イーです。オープン・スリーディー・エンジンの略で、ゲーム、映像、シミュレーションを作るための、オープンソースの 3D エンジンです。企業が財団の会員として開発を支えています。ロボットの用途では、ロス・ツーとつなぐ部品が、追加の部品集として提供されています。アール・エー・アイとのつながりもあり、アール・エー・アイの開発元の倉庫のデモは、ロス・ツー、オー・スリー・ディー・イー、アール・エー・アイの組み合わせで作られています。また、アール・エー・アイのベンチマークにもオー・スリー・ディー・イーを使うものがあり、外部の論文の評価に使われた例もあります。
