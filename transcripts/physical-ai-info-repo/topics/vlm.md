# VLM と VLA（聞くための原稿）

これは、ロボットに使われる VLM と、そこから一歩進んだ VLA についての話です。代表的なものを9つ紹介します。情報は、どれも2026年10月17日の時点で確かめたものです。なお、ふつうの用途の VLM どうしの比較は扱いません。

この話のポイントは3つです。

1つ目。VLM は画像と言葉を読んで、言葉で答えるモデルで、ロボットでは認識や計画といった「考える」部分を受け持ちます。VLA は、それに加えて、ロボットの動作まで出力するモデルです。

2つ目。誰でも使えるオープンソースのモデルとして、エヌビディアのコスモス・スリーやアイザック・グルートなどが、実用の段階に入っています。

3つ目。グーグル・ディープマインドのジェミニ・ロボティクスのように、計画を立てる VLM と、動作を受け持つ VLA を組み合わせる形も出てきています。

## まず、VLM と VLA の関係についてです

VLM は、画像と言葉を入力に取り、答えや説明や計画といった言葉を出力します。ロボットに使うときは、認識や計画を受け持ち、実際の体の動かし方は、別の仕組みに任せます。

VLA は、VLM を土台にして、出力にロボットの動作、例えば関節の目標の値などを加えたものです。Web の画像と文章で学んだ知識を、ロボットの制御に持ち込めることが狙いです。2023年のアールティー・ツーが、その初期の代表的な例です。

この2つを組み合わせる例もあります。ジェミニ・ロボティクスでは、VLM が計画を立て、VLA を「道具」として呼び出します。また、アイザック・グルートの最新の版は、VLM を内部の土台として使う VLA です。

## 次は、オープンソースのモデルを5つ紹介します

1つ目は、エヌビディアのコスモス・スリーです。2026年5月に発表された、フィジカルAI向けの基盤モデルです。1つのモデルで、言葉、画像、動画、音声、そして動作の並びを扱います。開発元は使い方として、3つを挙げています。複数の種類のデータを理解して推論する VLM として。物理的な環境の先の状態を予測する世界モデルとして。そして、ロボットに作業を学ばせるための土台としてです。大きさの違う2つの版が公開済みで、機器の上で動かす小型の版は、後から出る予定です。正式に公開され、クラウドのサービスとしても提供されているので、状態は実用です。

2つ目は、同じくエヌビディアのアイザック・グルートです。人型ロボットなどに向けた VLA で、最初の版の論文は2025年3月に公開されました。VLM が場面と指示を読み取り、拡散モデルという仕組みの部分が動作を作る、という2段の構成です。確認した時点の最新の版は、土台の VLM にコスモスの推論用の小型モデルを使い、ロボットの動作のデータに加えて、人の動画も学習に使っています。独自のロボットに合わせて追加で学習させる例も用意されています。開発元はこの版を一般提供の版としていて、状態は実用です。コードとモデルの重みは、別々のライセンスになっています。

3つ目は、フィジカル・インテリジェンスという会社のオープン・パイです。パイ・ゼロや、パイ・ゼロ・ポイント・ファイブといった VLA のコードと、学習済みのモデルを公開しています。2024年10月のパイ・ゼロは、学習済みの VLM の上に、動作を滑らかに作る仕組みを載せ、片腕、双腕、移動ロボットなど、いろいろな機体のデータで学習しました。2025年4月のパイ・ゼロ・ポイント・ファイブは、Web のデータなども混ぜて学習し、初めて入る家の中で、片付けのような長い作業をこなせることを示しました。ただし、説明書きで「実験である」とし、手元のロボットで動くとは限らないと断っているので、状態は研究段階です。

4つ目は、オープン・ブイエルエーです。2024年6月の論文で、誰でも使えるように公開された VLA です。パラメータは70億個で、実機のロボットの動作の記録、約97万件で学習しました。論文によれば、パラメータの数がおよそ7倍の、アールティー・ツー・エックスというモデルより、作業の成功率が高かったそうです。一般向けの GPU でも追加で学習できることも示しました。確認した時点では、最後の更新が2025年3月なので、状態は研究段階としています。

5つ目は、スモール・ブイエルエーです。2025年6月の論文で、小型の VLA です。論文によれば、10倍大きい VLA と同じくらいの性能で、1枚の GPU で学習でき、一般向けの GPU や CPU でも動かせます。コミュニティが安価なロボットで集めたデータで学習していて、コード、学習済みのモデル、学習データを公開しています。ロボット学習のライブラリ、ル・ロボットの一部として提供されていますが、ル・ロボットがまだ正式な1.0の版に達していないので、状態は研究段階です。

## 次は、初期の重要な論文を2つ紹介します

1つ目は、パーム・イーです。2023年3月の論文で、言語モデルを、身体を持つ作業に広げた、初期の VLM です。言語モデルに、画像やロボットの状態をそのまま入力として与えて一緒に学習させ、ロボットの作業の計画、画像についての質問への回答、画像の説明を、1つのモデルでこなしました。論文によれば、Web の多様なデータで学習するほど、ロボットの作業の成績も上がりました。

2つ目は、アールティー・ツーです。2023年7月の論文で、VLM をそのままロボットの制御に使う VLA の、初期の代表的な例です。ロボットの動作を文字の並びとして表し、Web の画像と文章のデータと、ロボットの動作のデータで、VLM を一緒に追加で学習させました。学習のデータに無い物や指示にも対応できることを示しました。

## 次は、製品を2つ紹介します

1つ目は、グーグル・ディープマインドの、ジェミニ・ロボティクス・イーアール・ツーです。2026年7月に発表された、ロボットの「計画を立てる頭脳」にあたる VLM で、前の版の後継です。人との会話、周りの理解、何段階もある作業の計画、動画からの進み具合の把握、そして複数のロボットの連携を受け持ちます。実際の動作は、開発者が「道具」として登録した VLA などに任せます。開発元によれば、開発者向けのサービスを通じて一般に使えるので、状態は実用です。

2つ目は、同じくグーグル・ディープマインドの、ジェミニ・ロボティクス・ツーです。2026年7月に発表された VLA です。開発元によれば、人型ロボットの全身や、双腕のロボットを動かせて、手の細かな操作も扱います。ロボットの機器の上で動かす軽い版も、同時に発表されました。一方で開発元自身も、指の多い手の細かな操作はまだ難しく、作業によって成功率に大きな差があると述べています。早期アクセスのパートナーに限って提供されているので、状態は研究段階です。

## 最後に、まとめです

VLM はロボットの認識と計画を、VLA はそこから動作の出力までを受け持ちます。2023年のパーム・イーとアールティー・ツーが、その流れの出発点になりました。

今では、エヌビディアのコスモス・スリーとアイザック・グルートが、オープンソースのまま実用の段階に入っています。一方、オープン・パイ、オープン・ブイエルエー、スモール・ブイエルエーは、研究段階のオープンソースです。

製品では、ジェミニ・ロボティクスが、計画を立てる VLM と、動作を受け持つ VLA を組み合わせる形をとっています。ただし VLA の方は、まだ限られたパートナー向けの段階です。

以上で、VLM と VLA の話を終わります。
